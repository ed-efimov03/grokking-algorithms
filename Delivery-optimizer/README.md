# Оптимизация доставки заказов в пиццерии
Чтобы запустить алгоритм, необходимо запустить скрипт delivery.py 
```bash
python3 ./Delivery-optimizer/delivery_optimizer.py 
```
Программа умеет работать двумя способами:
1. Через аргументы командной строки:
```bash    
    python delivery_optimizer.py --orders "[[2,5],[3,2],[1,4]]" --couriers 2
```
    
2. В интерактивном режиме (если аргументы не переданы):
```bash   
    Введите список заказов (формат: [[2,5],[3,2],[1,4]]):
        > ...
    Введите количество курьеров:
        > ...
```
